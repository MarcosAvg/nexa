# Código de Conducta — Nexa

## Nuestro compromiso

Nos comprometemos a que la participación en este proyecto sea una experiencia libre de acoso para todos, independientemente de edad, origen, discapacidad, etnia, identidad y expresión de género, nivel de experiencia, nacionalidad, apariencia personal, raza, religión, identidad u orientación sexual.

## Estándares

Se espera que las personas contribuyentes se comporten de manera respetuosa y colaborativa. Se consideran comportamientos positivos:

- Usar un lenguaje acogedor e inclusivo.
- Respetar los distintos puntos de vista y experiencias.
- Aceptar críticas constructivas con apertura.
- Centrarse en lo que es mejor para la comunidad.
- Mostrar empatía hacia otras personas.

No se toleran comportamientos de acoso, lenguaje despectivo, comentarios ofensivos, insultos personales, acoso público o privado, ni cualquier otra conducta que haga que el entorno sea hostil.

## Alcance

Este código aplica tanto en los espacios del proyecto (issues, pull requests, chats) como en espacios públicos donde la persona represente al proyecto.

## Aplicación

El mantenimiento del proyecto revisará y responderá a reportes de conducta. Toda persona que viole el código podrá ser suspendida o excluida del proyecto de forma temporal o permanente, según se considere apropiado.

Para reportar un incidente, abre un issue privado o contacta con el mantenimiento del proyecto.

## Atribución

Este Código de Conducta se basa en el [Contributor Covenant](https://www.contributor-covenant.org/), versión 2.1.
